# Profiles (M1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cho một tài khoản nhiều profile (tối đa 5) với gu xem riêng, switch qua lại trong phiên đăng nhập, PIN 4 số tuỳ chọn.

**Architecture:** `profiles` là thực thể con của `users`; 4 bảng tín hiệu xem (`favorite`, `watchlist`, `watch_progress`, `rating`) re-key từ `user_id` sang `profile_id`; profile hoạt động nằm trong phiên (`refresh_tokens.profile_id` + claim `sid`/`pid` của access token) nên PIN được server enforce trên mọi request. `comment`/`comment_report` giữ nguyên `user_id`.

**Tech Stack:** FastAPI, SQLAlchemy 2.0 async + Alembic, Pydantic v2, passlib (bcrypt), Redis (rate limit), pytest + respx; Next.js 15 App Router, TanStack Query v5, shadcn/ui, Playwright.

**Spec:** `docs/superpowers/specs/2026-09-17-profiles-and-recommendations-design.md`

```python
from sqlalchemy import (
    Boolean, ForeignKey, Index, SmallInteger, String, UniqueConstraint, Uuid, false,
)
from sqlalchemy.orm import Mapped, mapped_column

from app.db.base import Base, TimestampMixin

AVATAR_KEYS: tuple[str, ...] = (
    "popcorn", "rocket", "cat", "panda", "robot", "ghost",
    "alien", "ninja", "pirate", "dino", "star", "clover",
)
FALLBACK_AVATAR = "popcorn"


class Profile(Base, TimestampMixin):
    __tablename__ = "profiles"
    __table_args__ = (
        UniqueConstraint("user_id", "name", name="uq_profile_user_name"),
        UniqueConstraint("user_id", "position", name="uq_profile_user_position"),
        Index(
            "uq_profile_user_default",
            "user_id",
            unique=True,
            postgresql_where=text("is_default"),
            sqlite_where=text("is_default = 1"),
        ),
    )

    id: Mapped[uuid.UUID] = mapped_column(Uuid, primary_key=True, default=uuid.uuid4)
    user_id: Mapped[uuid.UUID] = mapped_column(
        Uuid, ForeignKey("users.id", ondelete="CASCADE"), index=True, nullable=False
    )
    name: Mapped[str] = mapped_column(String(32), nullable=False)
    avatar: Mapped[str] = mapped_column(String(32), nullable=False, default=FALLBACK_AVATAR)
    position: Mapped[int] = mapped_column(SmallInteger, nullable=False)
    is_default: Mapped[bool] = mapped_column(
        Boolean, nullable=False, default=False, server_default=false()
    )
    pin_hash: Mapped[str | None] = mapped_column(String(255), nullable=True, default=None)
```

```python
op.create_table("profiles", ...)              # đúng cột như model
op.add_column("favorite", sa.Column("profile_id", sa.Uuid(), nullable=True))
# ... watchlist, rating, watch_progress
op.execute("""
    INSERT INTO profiles (id, user_id, name, avatar, position, is_default, created_at, updated_at)
    SELECT gen_random_uuid(), id, 'Mặc định', 'popcorn', 0, true, now(), now() FROM users
""")
for table in ("favorite", "watchlist", "rating", "watch_progress"):
    op.execute(f"""
        UPDATE {table} t SET profile_id = p.id
        FROM profiles p WHERE p.user_id = t.user_id AND p.is_default
    """)
    op.alter_column(table, "profile_id", nullable=False)
    op.create_foreign_key(None, table, "profiles", ["profile_id"], ["id"], ondelete="CASCADE")
    op.create_index(...)   # + drop unique cũ (user_id, movie_slug), tạo unique mới
    op.drop_column(table, "user_id")
op.add_column("refresh_tokens", sa.Column("profile_id", sa.Uuid(), nullable=True))
op.create_foreign_key(None, "refresh_tokens", "profiles", ["profile_id"], ["id"], ondelete="SET NULL")
```

**Lưu ý SQLite cho test**: `gen_random_uuid()` chỉ có trên Postgres → trong `upgrade()` phát hiện dialect (`op.get_bind().dialect.name`) và dùng UUID sinh bằng Python (batch insert qua `sa.table`/`sa.text` với tham số) khi dialect là `sqlite`; trên Postgres giữ SQL set-based. `downgrade()` tái tạo `user_id` từ `profiles.user_id` rồi drop cột/bảng (dữ liệu profile phụ gộp về user — ghi comment trong migration).

```python
@dataclass(frozen=True)
class ActiveProfile:
    user: User
    profile: Profile
    session_jti: str | None

async def get_active_profile(
    token: str = Depends(oauth2_scheme), db: AsyncSession = Depends(get_db)
) -> ActiveProfile:
    payload = _decode_access(token)          # tách logic decode hiện có của _resolve_user
    user = await _load_active_user(db, payload)   # giữ nguyên thứ tự: type → user → is_active → banned

    return ActiveProfile(user=user, profile=profile, session_jti=payload.get("sid"))
```

```python
def _hash_pin(pin: str) -> str:
    return security.hash_password(pin)

async def verify_pin(db: AsyncSession, profile: Profile, pin: str | None) -> None:
    if profile.pin_hash is None:
        return
    if not pin:
        raise AppException("PIN required", "PIN_REQUIRED", 403)
    await _rate_limit_pin(db, profile.id)          # 429 khi vượt PIN_MAX_ATTEMPTS/PIN_WINDOW
    if not security.verify_password(pin, profile.pin_hash):
        raise AppException("Invalid PIN", "INVALID_PIN", 401)
```

- [ ] **Step 1: Viết `lib/profiles.ts`**

Theo pattern `apps/web/lib/moderation.ts` (queryKey + `apiFetch` + `useMutation` + invalidate):

```ts
export const PROFILE_KEYS = { all: ["me", "profiles"] as const };

export function useProfiles() {
  return useQuery({
    queryKey: PROFILE_KEYS.all,
    queryFn: () => apiFetch<ProfileList>("/api/v1/me/profiles"),
  });
}

export function useSwitchProfile() {
  const queryClient = useQueryClient();
  return useMutation({
    mutationFn: ({ id, pin }: { id: string; pin?: string }) =>
      apiFetch<SwitchResult>(`/api/v1/me/profiles/${id}/switch`, {
        method: "POST",
        body: JSON.stringify(pin ? { pin } : {}),
      }),
    onSuccess: (data) => {
      setAccessToken(data.access_token);
      queryClient.clear();
    },
  });
}
```

`useDeleteProfile` nhận `{id, pin?}`; `useSetProfilePin` nhận `{id, password, pin}`; lỗi trả về dùng `ApiError.code` để UI phân nhánh (`PIN_REQUIRED`, `INVALID_PIN`, `INVALID_PASSWORD`, `DEFAULT_PROFILE`, `PROFILE_LIMIT_REACHED`, `PROFILE_NAME_TAKEN`).
